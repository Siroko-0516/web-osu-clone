# Web osu! clone

An unofficial, open-source browser rhythm game experiment inspired by circle-clicking rhythm games.

## Play locally

Serve the `dist` directory with any static web server, or open `dist/index.html` in a modern browser.

## Included

- Mouse, keyboard (`Z` / `X`), and touch input
- Timing windows with 300 / 100 / 50 / miss judgements
- Score, combo, accuracy, health, results, pause, and retry
- Three generated demo difficulties
- Procedurally generated Web Audio tones; no bundled songs
- Responsive full-screen canvas playfield

## Project status

This first browser-playable release is an independent web implementation. It is not a binary conversion of osu!lazer; osu!framework's desktop rendering, audio, input, storage, and networking layers do not run unchanged in a browser.
